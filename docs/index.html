Xbox, 넷플릭스 5억 달러 제안 거절

Hacker News·10월 25일 16:00·AI 요약
넷플릭스가 Xbox 캐릭터 기반 콘텐츠 제작을 위해 7년 계약에 5억 달러를 제안했고, 마이크로소프트는 8억 달러를 제시해 협상이 결렬됐다. 마이크로소프트는 이제 파트너별로 소규모 계약을 모색하고 있다.
중요한 이유게임 IP의 미디어 라이선싱 전략이 독점 대형 계약에서 파트너별 소규모 계약으로 전환된다. 개발 중인 프로젝트의 IP 활용 방식이나 협업 구조에 직접적인 영향을 미치지는 않는다.

테스트가 세 번 실패했지만 LLM은 옳았다

dev.to·10월 25일 16:00·AI 요약
테스트가 실패할 때 코드를 고치는 것이 일반적이지만, 에이전트 보안 도구인 agentic-suite의 필드 테스트에서 LLM이 실제 상황을 올바르게 판단한 사례가 세 번 있었다.
