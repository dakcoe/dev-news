dev-news 가 다루는 정보

처리 목적

dev-news는 GitHub 로그인을 한 이용자에게 보관함과 읽음 표시를 여러 기기에서 똑같이 보여 주고 로그인 상태를 유지하기 위해서만 개인정보를 처리합니다. 로그인은 선택 기능이며, 로그인하지 않으면 읽은 기사와 보관함은 사용하는 브라우저에만 기록되고 서버로 보내지 않습니다.

처리하는 항목과 수집 방법

  • GitHub 계정의 숫자 ID: 로그인할 때 GitHub에서 받습니다.
  • 보관한 기사의 주소, 제목, 게시 달, 종류, 짧은 설명과 보관한 시각: 보관 버튼을 누를 때 저장합니다.
  • 읽은 기사의 주소와 읽은 시각(최근 1,000건): 기사를 열 때 저장합니다.
  • 로그인 상태를 유지하는 세션 식별자와 만료 시각

GitHub 계정의 이름, 이메일 주소, 프로필 사진, 비밀번호와 GitHub 접근 토큰은 저장하지 않습니다. 로그인할 때 GitHub에 요청하는 권한은 공개 프로필 읽기(read:user) 하나입니다.

보유 기간과 파기

세션은 30일 동안 보관하고, 만료되면 다음 요청 때 지웁니다. 계정, 보관함(최대 2,000건), 읽음 표시(최근 1,000건)는 탈퇴할 때까지 보관합니다.

탈퇴하면 데이터베이스에서 그 계정의 모든 기록을 바로 지우며, 지운 기록은 되살릴 수 없습니다.

제3자 제공

개인정보를 다른 사람이나 회사에 제공하지 않습니다.

처리 위탁과 국외 보관

서버와 데이터베이스는 Cloudflare가 운영하며, 위 항목을 다음과 같이 국외에 보관합니다.

  • 받는 자: Cloudflare, Inc.(미국, 101 Townsend St, San Francisco, CA 94107, privacyquestions@cloudflare.com)
  • 위탁하는 일: 로그인 처리 서버(Workers)와 데이터베이스(D1) 운영
  • 보관 국가: 아시아·태평양 지역의 Cloudflare 데이터센터. 정확한 국가는 Cloudflare가 정하며 공개하지 않습니다. 요청은 이용자와 가까운 Cloudflare 데이터센터에서 처리됩니다.
  • 시기와 방법: 로그인, 보관, 읽음 표시를 할 때마다 암호화된 연결(HTTPS)로 전송합니다.
  • 보유 기간: 위 「보유 기간과 파기」와 같습니다.
  • 거부 방법: 로그인하지 않으면 전송되지 않습니다. 이 경우 보관함과 읽음 표시는 사용하는 브라우저에서만 유지됩니다.

이 보관은 이용자가 요청한 동기화 기능을 제공하는 데 필요하여 처리방침 공개로 갈음합니다(개인정보 보호법 제28조의8 제1항 제3호 가목).

이용자의 권리와 행사 방법

보관함과 읽음 표시는 사이트에서 직접 보고 지울 수 있습니다. 소개 화면의 탈퇴를 누르면 모든 기록이 지워지고 GitHub 앱 승인도 취소됩니다. 열람, 정정, 삭제, 처리 정지 요청은 아래 연락처로 보내 주시면 지체 없이 처리합니다.

안전성 확보 조치

GitHub 접근 토큰은 로그인 순간에만 쓰고 저장하지 않습니다. 세션 쿠키는 스크립트가 읽을 수 없고(HttpOnly) 암호화된 연결에서만 전송되며(Secure), 로그인 서버 주소에만 보냅니다. 데이터베이스는 운영자의 Cloudflare 계정으로만 관리합니다.

쿠키

로그인한 경우에만 다음 쿠키를 씁니다: 로그인 상태를 유지하는 세션 쿠키(30일), 로그인 과정에서만 쓰는 확인용 쿠키(30분), 탈퇴 확인용 쿠키(10분). 브라우저 설정에서 쿠키를 막을 수 있지만 그러면 로그인할 수 없습니다.

광고와 방문 통계 도구는 쓰지 않습니다.

자동으로 전송되는 정보

페이지가 글꼴(jsDelivr), 기사 썸네일(각 원문 사이트), GitHub 프로필 이미지를 그 서버에서 직접 불러오므로, 접속한 기기의 IP 주소 같은 접속 정보가 그 서버에 전달됩니다. dev-news는 이 정보를 받거나 저장하지 않습니다.

만 14세 미만

만 14세 미만은 로그인 기능을 쓸 수 없습니다. 만 14세 미만의 기록이 확인되면 지웁니다. 로그인 없이 기사를 읽는 데에는 제한이 없습니다.
