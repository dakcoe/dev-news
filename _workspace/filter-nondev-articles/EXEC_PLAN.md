## 원인 (조사 완료)

`TRUSTED`가 원인이 아니라 **증상**이다.

`config.yaml`의 키워드 140개를 세어보니 **한국어 키워드가 0개**다. 전부
`python`·`llm`·`kernel` 같은 영어인데 긱뉴스 제목은 한국어라 이 필터를
구조적으로 통과할 수 없다. 그래서 `build.py`의 `TRUSTED`에 넣어 검사를
면제한 것이다 — 안 그러면 긱뉴스가 통째로 사라진다.

  필터가 한국어를 못 읽음 → 면제 → 비개발 기사 유입

**그래서 TRUSTED만 떼면 더 나빠진다.** 면제된 4개 출처(148건)에 현행 필터를
적용하면 38건이 떨어지는데, 그중 절반 이상이 멀쩡한 개발 기사다:

  [github]   actions / checkout          ← 깃허브 액션 공식 저장소
  [geeknews] The Twelve-Factor App (2011) ← 개발 고전
  [devto]    Delete Your padding-bottom Aspect-Ratio Hack ← CSS 키워드가 목록에 없음
  [rss]      1%가 겪은 버그 고쳐야할까요?

키워드 화이트리스트로는 개발 주제를 다 덮을 수 없다. CSS·git·인터뷰·저장소명이
빠져 있고, 앞으로도 계속 새는 구멍이 생긴다.

## 접근법

**방향을 뒤집는다 — "개발이면 통과"가 아니라 "명백히 비개발이면 차단".**
개발 주제는 무한히 다양하지만 걸러내고 싶은 주제는 좁다(정치·선거·전쟁·감시·
스포츠·연예·기후).

차단은 **차단어가 있으면서 동시에 개발 키워드가 하나도 없을 때만** 한다.
`캘리포니아주 의회, 연령 확인법에서 Linux 면제`처럼 정치 어휘를 쓰지만 개발
기사인 경우를 살리기 위해서다. 그리고 차단은 `TRUSTED`에도 적용한다 —
면제 대상은 화이트리스트(통과 조건)이지 블랙리스트(차단 조건)가 아니다.

**실측(8월 전체 1,272건): 13건 차단, 12건 정타.**

  텍사스 Flock 감시 카메라 3,200대 / DHS 세관법으로 언론인·노조 감시
  아이슬란드 EU 가입 국민투표 / 캐나다 대미 관세 맞대응
  트럼프 행정부 연구비 취소 키워드 목록 / 2026 슈퍼 엘니뇨
  북방 갈매기 / 뉴멕시코 항공기 추락 GPS 교란 …

작업 중 확인한 함정 두 가지를 테스트로 고정한다:

| 함정 | 사례 | 대응 |
|------|------|------|
| 영어 부분문자열 | `war`가 `software`·`hardware`에 걸림 | 영숫자 단어경계 |
| 한국어 부분문자열 | `배우`가 `배우다`에 걸림 | 모호어를 목록에서 제외 |

## 한계 (이 방식으로 못 잡는 것)

차단 목록은 **정치색이 있는 것만** 잡는다. 아래는 전부 AI가 소재라 개발
키워드에 걸리고 차단어도 없어서 통과한다:

  소니·워너 Anthropic 저작권 소송 / 호주 부당해고 AI 조언 판결
  보코니대 학점 실험 / 영국 일자리 시장 분화

근본 해결은 요약 LLM 호출에 `분류: 개발|주변|무관` 필드를 추가하는 것이다
(추가 API 호출 0회 — 이미 부르는 그 호출에 줄 하나를 더 받는다). 다만
`build.py`의 `pick(top_n)`이 요약보다 먼저라 선별 순서 조정이 필요하고,
프롬프트·예산이 얽혀서 **별건으로 남긴다.**

## 완료 기준

- 명백한 비개발 기사가 TRUSTED 출처에서도 차단된다
- 개발 키워드를 동반한 기사는 차단어가 있어도 통과한다 (캘리포니아 Linux 건)
- `software`·`hardware`가 `war`로 차단되지 않는다
- `block_keywords`가 비어 있으면 현행과 동일하게 동작한다
- pytest 전체 통과
