## 목표

LLM 요약문에 한자 외의 외국 문자(태국 문자, 가타카나·히라가나, 키릴 등)가 새어 나와 게시되는 문제를 막는다.
현재 감지 필터가 CJK 한자 블록만 검사해서 그 외 스크립트는 전부 통과하고 있다.

## 접근법

블랙리스트(한자 범위 나열) → 화이트리스트(허용 문자 외 전부 차단)로 반전한다.
시스템 프롬프트가 이미 "한글·영문·숫자·문장부호만"을 선언하므로 검증 규칙을 동일하게 맞춘다.

- `HANJA_RE` → `FOREIGN_RE`: 한글(가-힣, 자모), ASCII, 일반 문장부호·통화기호 외의 문자를 감지
- 기존 파이프라인(재생성 1회 → 번역 치환 1회 → 미게시)은 그대로 유지, 감지 정규식만 교체
- `HANJA_FIX_PROMPT`를 "중국어 한자" → "외국어 단어" 로 일반화
- 요약문 끝에 붙는 "없음" 템플릿 누출("… 계획이다. 없음")을 후처리로 제거
- 이미 게시된 오염 데이터는 별도 태스크로 분리 (이번 범위 아님)

## 단계별 계획

2. GREEN: `FOREIGN_RE` 화이트리스트 정규식 도입, `_translate_hanja` → `_translate_foreign` 일반화, "없음" 후처리 추가
