## 접근법

- **허브**: 첫 화면은 카테고리 카드 그리드(이름·건수·무인증 수·대표 API 3개 미리보기).
  출처 세그먼트(전체/한국판/Public APIs)로 섹션 필터. 전체일 땐 한국판/본가 섹션 분리.
- **카테고리 화면**: 카드 클릭 → 해당 카테고리의 API 목록. 각 항목은 아코디언 —
  접힘: 이름+KR/인증 배지+설명 한 줄, 펼침: 전체 설명 + 원문 바로가기 링크.
- **검색**: 상단 바(h1·sub·검색·세그)는 모든 하위 뷰에서 동일 마크업으로 고정하고
  본문(#apibody)만 부분 갱신 — 허브→검색 전환 시에도 input이 교체되지 않아
  한글 IME 조합 유지. 검색 결과는 카테고리 그룹 헤더 + 아코디언 행.
- 데이터·파이프라인(apis.json)은 변경 없음. template.html의 API 뷰 JS/CSS만 교체.
- docs/index.html은 실데이터 재렌더로 즉시 반영 (수집 시각 보존, 기존 관행).
