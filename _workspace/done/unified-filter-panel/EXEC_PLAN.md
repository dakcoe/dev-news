## 접근법

- 패널 구성(위→아래): 헤더 "필터"+접기 / 정렬(라디오 3) / 기간(라디오 4) /
  안 읽음(체크) / 출처(전체+소스별, 색점+건수, 단일 선택 유지) / 태그(기존 그룹 멀티) / 초기화 푸터.
- 상단 바는 검색창만 남긴다. 소스 칩 줄(chipsHTML)은 제거 — 출처는 패널로 이동.
- tagrow 버튼: "태그"→"필터"로 개명, 뱃지 = 활성 필터 수(태그 n + 출처 + 기간 + 안읽음).
  정렬은 보기 방식이라 뱃지에 세지 않는다.
- 초기화 = 태그·출처·기간·안읽음 리셋 (정렬은 유지).
- 기존 동작 의미 불변: 출처 단일 선택, 태그 멀티(OR), localStorage 저장 항목 동일.
